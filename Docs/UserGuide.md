# Semiconductor Limit Editor 3.0.0

Windows x64，依赖框架的单 EXE 发行版。先安装 **Microsoft .NET 8 Windows Desktop Runtime x64**（不是仅安装 ASP.NET/Core Runtime）：https://dotnet.microsoft.com/download/dotnet/8.0 。解压 ZIP，运行 `SemiconductorLimitEditor.exe`。不需要安装 Excel。保留基线 MIT 许可及历史。

- 直接进入分析主界面，移除产品/数据管理窗口。使用独立 `%LOCALAPPDATA%\SemiconductorLimitEditor` 设置目录。
- Test Item 主列表仅新增“新 LSL、新 USL、良率变化”。名称内的参与勾选与分类色标独立于“关注”；分类筛选、批量开启、原限值恢复和规则 JSON 保存/加载。
- 原始良品参考冻结分类；冲突/缺测项默认关闭。不良品也全通过或没有不良样本的项目仍默认有效。更换分 BIN 设置时明确重建基准。
- 每条原始 DUT 独立重判，缺测/无效/异常待确认，空参与集合保留原 BIN。原等级不变保持原 BIN，受影响记录同步改 SBIN 与 HBIN。支持原始多对识别、Pass/PartialPass 参考池与恢复等级、统一新增 Fail 目标。
- 首测/末测整体统计，良品优先按重判后的完整记录选择；不把前次测量补到后次。界面整体统计覆盖全部导入来源，单项变化按当前 Site/Wafer/样品范围显示。
- 批量导出创建独立新目录，一进一出，附规则和逐记录变化/待确认清单；源文件指纹验证、失败/取消不发布部分结果。
- CSV 布局完整时保留编码、分隔符、引号、多行表头与测量原文；缺少可写限值行或双 BIN 列时转为标准化 CSV 并附 `.ini`。
- STDF 顺序写回 PTR/MPR 实际 R*4 限值、逐项判定、受影响 PRR 双 BIN/标志，并同步现有 HBR/SBR/PCR/WRR/TSR 计数；保留未修改记录、未知扩展、原大小端及 gzip。继承限值按执行记录显式写出，避免修改默认值影响其他规格。

## 使用

1. 打开 STDF/STD/gzip，或先在设置加载 CSV 行列配置后打开 CSV。
2. 设置 → **良率调整与分 BIN**：确认原始 Pass/PartialPass 的 `SBIN:HBIN` 及三个导出目标。
3. 查看分类原因，编辑新上下限（空白清除单侧），必要时开启冲突/无效项；检查整体及单项良率变化。
4. 点击 **导出重判文件**，选择父目录；核对规则及变更清单后在下游工具验证。

## 明确边界

- 有结构恢复警告的 STDF 可以预览，但阻止原格式导出；不把截断或缺失结构伪装为完整标准文件。
- MPR 同记录多结果共用限值，编辑联动；参与状态可逐结果选择。FTR 只能切换参与，不支持改数值限值。
- 统一配置新增 Fail BIN；没有启用可选的“失败测项优先级映射”。待确认始终保留原 BIN。
- PRR/TSR 等计数按原始测试记录口径，不是去重复 DUT 数。BIN 名称/原测试测量统计（min/max/sum）保留原记录；测量本身不改变。
- 此工具不覆盖原数据；建议保留导出目录中的规则和清单，与业务测试规范核对后使用。
