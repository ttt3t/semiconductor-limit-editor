# Semiconductor Limit Editor 3.0.1

Windows x64，依赖框架的单 EXE 发行版。运行前安装 **.NET 8 Windows Desktop Runtime x64**：https://dotnet.microsoft.com/download/dotnet/8.0 。解压后运行 `SemiconductorLimitEditor.exe`。不需要 Excel。

## 本次修改

- **BIN 设置分开输入**：原始 Pass / PartialPass 支持多行配置，每行分别填写 SBIN 与 HBIN；导出 Pass / PartialPass / Fail 同样分开输入，验证整数范围与冲突。兼容 3.0.0 的配置文件，保留原值，不自动交换。例如实际 SBIN=1000、HBIN=1，请在两个框分别填写 1000、1。
- **列表滚动**：新限值单元格平时仅显示文本，双击或 F2 创建当前单元格编辑框；Enter/离开单元格提交，Escape 取消。参与开关使用轻量绘制，保留键盘操作和辅助功能。FTR 限值显示“—”并禁止数值编辑。
- **后台重算与进度**：显示实际计算阶段和百分比，支持取消及手动重新计算；重算期间可以滚动和操作 GUI。连续修改会取消旧任务，后台一次执行一个预览，过期结果不能覆盖最新设置。失败/取消保留上次完成的预览，未完成结果禁止导出。
- **大文件内存与读取**：原始分类、DUT 重判和单项良率优先使用已加载的数值列；只对缺测/无效/不适用状态读取原文，使用可复用缓冲，不按测项反复分配整行。预览持有独立缓存句柄，切换数据/关闭窗口时正确取消与释放。
- **提示与诊断**：没有识别到原始良品时明确警告，未验证的默认分类使用灰色标记；重算失败日志保存在 `%LOCALAPPDATA%\SemiconductorLimitEditor\Logs`。

## 验证

现有 CSV / STDF 大小端 / gzip、双 BIN、计数、复测、原文保留回归；新增 50,000 条记录 × 256 测项（1280 万测量值）的合成文件压力测试，验证重算结果、分组统计、内存分配上限、取消后缓存一致性和读取句柄生命周期。Windows 工作流验证实际 WPF 编辑/撤销、BIN 输入、5000 测项列表虚拟化、后台进度、GUI 心跳、取消和连续编辑。

压力测试使用合成数据，未取得用户发生崩溃时的原始文件或崩溃转储，因此不把本次修复视为所有异常文件崩溃的唯一原因。

3.0.0 的功能范围与导出约束仍适用：原始文件不覆盖，重判导出一进一出并保留全部历史；有结构恢复警告的 STDF 只预览，FTR 通过参与状态控制，未实现可选的失败测项优先级映射。详细说明见仓库 `Docs/UserGuide.md`。
