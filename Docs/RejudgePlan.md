# STDF / CSV 阈值修改与重新分 BIN：完整改造方案

本方案以用户最新修正为准。仓库基线来自 `ttt3t/semiconductor-data-analyzer` 2.0.12，提交 `fa93b549c0b4a04b3daf21e5c53d8d55c923d76f`。

当前阶段：3.0.0 实现。使用方法、验证方式及明确边界见 [3.0.0 发行说明](ReleaseNotes-3.0.0.md)；本文保留原始需求与建议。

本文整合原始方案及后续修正，覆盖主界面、测项分类、参与规则、DUT 重新分 BIN、复测统计、STDF / CSV 写出、性能和实施顺序。以本文为后续开发入口；其中标明“建议”的细节与已经确认的需求分开说明。

已确认的核心要求：

1. 新工具废弃数据管理界面，在现有 Test Item 主列表新增新 LSL、新 USL、良率变化三列。
2. 测项默认为有效项；良品失败归冲突项，良品无数据归无效项。良品和不良品都通过、或没有不良样本时，仍为有效项。
3. 默认只让有效项参与 DUT 重新分 BIN，冲突项和无效项由用户手动开启。
4. 设置中指定 Pass / PartialPass 的 SBIN 和 HBIN；受调整影响的 DUT 导出时两个 BIN 同时更新。
5. 导出真实修改后的 STDF / CSV，使用公开独立仓库 `ttt3t/semiconductor-limit-editor`。

## 1. 产品范围与仓库

- 新工具使用公开独立仓库 `ttt3t/semiconductor-limit-editor`。
- 新工具彻底移除数据管理界面、入口及产品目录读写，直接启动现有分析器主界面；原分析器仓库继续独立保留。
- 不新建一套良率修改窗口，直接扩展现有 Test Item 主列表，保留导入、搜索、图表、晶圆 / Site 浏览及复测记录查看。
- 支持 STDF / STD / gzip 与 CSV，目标是导出真实修改阈值和 DUT 分 BIN 的新文件。
- 不覆盖原文件；批量导出默认一进一出，保留测量原文、记录顺序、全部测试历史、时间及身份。

## 2. 主列表只新增三列

| 新列 | 行为 |
| --- | --- |
| 新 LSL | 可编辑的新下限；初始化为原下限，支持明确清除单侧限值、粘贴与恢复原值 |
| 新 USL | 可编辑的新上限；初始化为原上限，检查有限数值、单位和 LSL ≤ USL |
| 良率变化 | 当前行同一统计范围内的单项新良率减原良率，以百分点显示；悬停查看原 / 新良率及样本数 |

原 LSL / USL 列保留用于对照。“良率变化”默认指单项规格良率变化，不把多个测项的变化相加充当整颗 DUT 良率；工具栏另显示整体原 / 新良率、恢复数、新增不良数、待确认数。

测项名称单元格内增加分类色标和参与计算勾选框，不另增分类列。原“关注”继续用于图表 / 导出选择，不与“参与重新分 BIN”混用。分类原因和涉及良品数可悬停查看，也可按分类筛选及批量开启参与。

同一测项的规则在各 Site / Wafer 统计行之间共享，数值修改联动；明确属于不同原始规格、名称或 MPR 通道的项目不误绑定。

## 3. 三类测项及默认参与状态

分类依据是原文件的原始阈值、有效性 / 判定标志与原始良品参考样本，分类基准在开始调整前建立并固定。更改新阈值不自动改变分类或参与开关。

“过测”在此表示已取得有效测量并通过原判定；“不过测”表示有有效失败结果；无数据、未执行、无效测量等单独识别，不能当作数值 0。

| 分类 | 判定依据 | 默认参与 |
| --- | --- | --- |
| 有效项 | 默认类别。原始良品都有有效数据且通过；不良品可有失败结果，也可以全部通过，当前无不良样本时仍归有效项 | 开启 |
| 冲突项 | 至少有一条原始良品参考记录在该项有明确失败 / 超限 | 关闭，用户可手动开启 |
| 无效项 | 没有明确良品失败，但至少有一条原始良品参考记录在该项没有有效数据、未参与测试或测量无效 | 关闭，用户可手动开启 |

用户最后修正：原始良品全部有数据并通过，而不良品也全部通过或没有不良样本的项目，归**有效项，默认参与**，不再归无效项。

若同一测项同时出现良品失败与良品无数据，主分类采用“冲突项”，提示同时保留两类原因。没有原始良品参考样本时保留默认有效项，并提示“缺少良品样本，未验证分类”，不伪造已通过的证据。

基准范围按导入来源、产品 / 程序与规格上下文确定。普通表格搜索或图表浏览不重新分类、不覆盖手动开关；更换源文件或原始良品识别配置后，明确重新建立基准。

原始良品参考池可以选择只包含 Pass，或同时包含 PartialPass；该选择只控制参考人群，不自动把导出结果都降为或提升为同一等级。

## 4. DUT 重新分 BIN

默认只使用开启的有效项。冲突项、无效项只有用户手动勾选后才进入计算。未参与项目既不贡献失败，也不因其缺测阻止新 Pass；不会沿用旧方案中“所有未修改项目一律参与”的行为。

对每条原始 DUT 测试记录：

1. 只检查参与集合，按新阈值与可用的真实测量重新比较。
2. 任一参与项明确失败，则新结果为 Fail。
3. 参与项全部适用且已完成、有效并通过，且 DUT 本身没有未解决的终止 / 身份等异常，才可得到确认通过。
4. 无明确失败，但参与项缺测、无效或 DUT 记录不完整，标记待确认。手动开启无效项不等于把缺失测量认作通过。
5. 所有测项都取消参与时，显示“未启用判定规则”，保留原 BIN，不以空集合得出全良。

默认沿用原等级：原 Pass / PartialPass 仍通过时保留其等级；原 Fail 恢复为良品时，使用设置中选择的目标等级（Pass 或 PartialPass，建议默认 Pass）。只有一组新上下限，不能凭空推导第二套 PartialPass 规格或功能档位。

原始测量与逐项真实失败标志不因取消参与而删除或伪造。STDF 没有统一的字段表达此界面的“参与”开关，故参与集合、分类和 BIN 策略必须随规则方案 / 导出清单保存；新 DUT BIN 按这个明确的参与集合生成。

## 5. 设置中的 Pass / PartialPass SBIN 与 HBIN

新增专门的“良率调整与分 BIN”设置，至少包含：

- Pass 的 SBIN / HBIN 配置。
- PartialPass 的 SBIN / HBIN 配置。
- 原始良品参考池是否包含 PartialPass。
- 恢复芯片写为 Pass 还是 PartialPass。
- 新增 Fail 的目标 SBIN / HBIN，及可选失败测项优先级映射。
- 待确认结果的处理方式，默认保留原 BIN 并列入清单，不将其写为确认良品。

建议把原始识别和导出目标分开：原始分类可匹配多对 SBIN + HBIN，每个等级指定一对导出目标。使用成对规则可以允许相同 HBIN 下不同 SBIN 分属 Pass / PartialPass；只有完整 BIN 对重叠或存在冲突时才提示修正。缺少所需 BIN 信息、或 SBIN / HBIN 互相矛盾的记录提示待核对，不默认为良品。

此处的成对匹配、恢复默认等级、冲突优先级等属于补充建议；实际开发时需在设置中明确展示，避免隐含决定。

## 6. 只改受影响 DUT，同时修改两个 BIN

“受影响”包含：Pass / PartialPass / Fail 状态发生变化，或明确的主失败原因与目标 BIN 映射发生变化。

| 原结果 → 新结果 | SBIN / HBIN 处理 |
| --- | --- |
| Fail → Pass | 同时写为指定的 Pass SBIN 和 HBIN |
| Fail → PartialPass | 同时写为指定的 PartialPass SBIN 和 HBIN |
| Pass / PartialPass → Fail | 同时写为所配置的新 Fail BIN 对 |
| 同等级且没有需要重分的主失败原因 | 保持原始 SBIN 和 HBIN，不批量改写 |
| 待确认 | 默认保留原 BIN，记录不确定原因，不输出虚假的确认良品 |

不能只修改 HBIN 或只修改 SBIN。原等级未变时，不因用户更改了某个测项阈值就把所有 DUT 统一刷成目标 BIN。

## 7. 单条记录与复测统计分开

每个原始测试记录单独重判，输出写回其对应 DUT 记录。原始测试历史完整保留，不能用前一次测量补齐后一次 PRR。

芯片良率默认以整条末次记录统计，可切换首测。如保留“良品优先”，先逐条重判，再按新结果选取最新良品；没有良品取最新记录。CP 沿用批次 / 晶圆 / 坐标，FT 沿用批次 / UUID，身份不足的记录独立保留。

统计分母和单位在原 / 新对比中必须相同，区分测试记录数与去重复 DUT 数。不把现有缺测概率预测结果写成真实 BIN。

## 8. STDF / CSV 导出

### STDF

新增基于原记录流的写出器：

- 顺序读取，保留未修改记录、未知扩展及原始顺序，支持原大小端和 gzip；不从当前主表重建并丢弃其他 STDF 信息。
- 更新被调整的 PTR / MPR 限值、可选字段与继承默认值，并按实际规格更新逐项判定。保留硬件告警、未执行、无效等真实标志。
- 对受影响 DUT 同步更新 PRR 的 SBIN、HBIN 和相应 DUT 判定标志。
- 同步更新受影响的 HBR / SBR、PCR、WRR、TSR 等计数与汇总，避免新 PRR 搭配旧 BIN 计数。逐项失败计数与参与集合下的 DUT 判定分别按其真实口径统计。
- 使用稳定原始记录定位及测项身份，不能仅靠列表序号或显示编号 `[1]` 写回。
- STDF R*4 限值的实际可写值用于界面预览、判定和导出，保持单位及包含边界一致，避免精度舍入后良率变化。

MPR 一条记录内多个结果共用上下限，新 LSL / USL 必须联动该组；不能给同一 MPR 各结果写不同限值而不改变结构。参与开关也需显示该共享关系；如希望逐通道独立改限，另设计明确的记录结构转换。

沿用 2.0.12 带警告恢复导入。不完整来源可以预览和恢复可读数据，但缺失测量、BIN、身份不伪造；导出前列明无法恢复的结构，不宣称已修复为完整标准文件。

### CSV

有明确布局时保留原编码、分隔符和多行表头，更新限值及受影响行的 SBIN、HBIN、结果，测量值保留原文。缺少可写的限值行或双 BIN 列时提供标准化 CSV 和配套配置，明确展示格式变更。

导出旁附规则方案和简短变更清单，记录参与集合、原 / 新限值、分类依据、BIN 对映射、DUT 变化数和警告。

## 9. 实现与性能

复用现有导入、主列表虚拟化、数值列、图表和 Map 渲染。新增独立的测项规则状态、参考分类、逐记录判定、BIN 对配置及流式写出服务。主列表扩展现有 TestItemSummary，多个分组行引用同一规则状态。

阈值编辑延迟触发后台计算，取消过期任务；只重新比较受影响测项，利用每条记录的失败 / 未知计数更新 DUT 结论。共享测量列，不增加第二份完整矩阵。分类诊断和手动参与开关分开存储。

新工具使用独立设置与方案目录，不读写旧管理目录。修改范围限定在新仓库，保留可追溯的原始 2.0.12 基线历史。

## 10. 开发顺序

1. 移除数据管理入口和界面，保留分析器作为唯一主界面。
2. 主列表新增三列，接入三类测项、参与开关及原始基准冻结。
3. 接入 Pass / PartialPass 的 SBIN + HBIN 设置、逐条重判和 DUT 良率对照。
4. 实现 CSV 和 STDF 的真实阈值 / BIN 写出、汇总同步及批量导出。

3.0.0 已实现上述主要流程。可选失败测项优先级映射暂未启用；待确认保留原 BIN；结构恢复警告来源仅预览，不输出伪完整 STDF。详见发行说明。
